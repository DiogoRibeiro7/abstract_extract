# Code of Conduct

## Our standard

This project welcomes technical discussion, bug reports, feature proposals, documentation improvements, and code contributions.

Participants are expected to communicate professionally and focus on the technical substance of the work.

Examples of constructive participation include:

- giving specific, actionable feedback;
- explaining disagreements with evidence or reproducible examples;
- distinguishing technical criticism from personal criticism;
- respecting different levels of experience and different technical approaches;
- keeping issue and pull-request discussions relevant to the repository.

Unacceptable behavior includes harassment, personal attacks, discriminatory language, threats, deliberate disruption, or publishing another person's private information without permission.

## Scope

This Code of Conduct applies to repository issues, pull requests, discussions, reviews, and other project spaces maintained by the repository owner.

## Reporting

For ordinary disagreements or contribution problems, use the relevant GitHub issue or pull-request discussion.

Do not use public issues to disclose security vulnerabilities, credentials, private data, or exploit details. Follow [SECURITY.md](SECURITY.md) for security-sensitive reports.

Serious conduct concerns should be reported privately to the repository owner through an available private GitHub contact channel.

## Enforcement

The repository owner may edit, hide, lock, or remove contributions that violate these expectations and may restrict participation when necessary to protect the project and its contributors.

Enforcement decisions should be based on observable behavior in project spaces rather than technical disagreement itself.
